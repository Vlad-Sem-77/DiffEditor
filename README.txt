║         DiffEditor — сравнение и редактирование файлов       ║
╚══════════════════════════════════════════════════════════════╝

Поддерживаемые форматы: .txt  .html  .htm  .ipynb  .py
Платформа: Windows 10 / 11, x32 и x64

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
БЫСТРЫЙ СТАРТ (Python уже установлен)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Установите Python 3.10+ (https://python.org/downloads/)
   При установке поставьте галку «Add Python to PATH»

2. Запустите приложение двойным кликом по файлу:
       run.bat

   Или из командной строки:
       python diffeditor.py

Никаких сторонних библиотек не требуется — только стандартная
библиотека Python (tkinter встроен).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
СБОРКА АВТОНОМНОГО .EXE (без установки Python на целевом ПК)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Установите PyInstaller:
       pip install pyinstaller

2. Соберите один файл (рекомендуется):
       pyinstaller --onefile --windowed --name DiffEditor diffeditor.py

   Флаги:
     --onefile    → один .exe-файл (~10–15 МБ)
     --windowed   → без консольного окна
     --name       → имя выходного файла

3. Готовый .exe будет в папке:
       dist\DiffEditor.exe

4. Для x32 (32-bit) .exe установите 32-битный Python и повторите
   шаг 2 на 32-битном интерпретаторе.

📂 Открыть    — загрузить файл (.txt/.html/.ipynb/.py) с диска
💾 Сохранить  — сохранить отредактированный текст
⟳ Сравнить   — запустить diff вручную
⬆ / ⬇        — перепрыгивать между блоками изменений

Авто-сравнение: при включённой галке diff обновляется в
реальном времени по мере набора текста (задержка 350 мс).

ЦВЕТА ПОДСВЕТКИ
  🟢 Зелёный фон  — добавленные строки / вставленные символы
  🔴 Красный фон  — удалённые строки / удалённые символы
  🟡 Жёлтый фон   — изменённые символы внутри строки

Подсветка работает посимвольно: если в середине строки
изменено одно слово, меняется только оно, а не вся строка.

ПОДДЕРЖКА .IPYNB
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Jupyter Notebook отображается как отформатированный JSON
(indent=2). Diff и редактирование работают в полном объёме.
При сохранении JSON валидируется — неверный файл не запишется.

Файлы .py сравниваются и редактируются как обычный текст.
